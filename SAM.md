# SAM

Investigation Here: [SAM](https://blueteamlabs.online/home/investigation/sam-d310695187)

## What is the attacker IP, and what is the port that they got a reverse shell on?
* **Answer**: 172.16.0.5, 80
* Found within the Sysmon logs, matched the process ID (5056), parent PID 3888 with the execution of PowerShell.
```
"DestinationIp": "172.16.0.5",
"DestinationIsIpv6": false,
"DestinationPort": 80
```
## What's the name of the malicious file that gave remote access to attacker?
* **Answer**:  sample_template.hta 
* Found within the Sysmon logs, searched for events with the Downloads folder 
```
"ParentCommandLine": "\"C:\\Windows\\System32\\mshta.exe\" \"C:\\Users\\Sam\\Downloads\\sample_template.hta
```
## What is the process that has been called by the payload upon execution?
* **Answer**: powershell.exe 
* Found within the parent command of Sysmon logs EventID 1 as well as matching PIDs.  
``` "CommandLine": "\"C:\\Windows\\System32\\WindowsPowerShell\\v1.0\\powershell.exe\```
## Knowing the payload name and process name, if the payload was generated by msfvenom, what would be the format option that the attacker would’ve used?
* **Answer**: hta-psh
* Conducted some research to find the format that fit powershell and hta 
## What property in the executed script says that the process runs without using the operation system shell?
* **Answer**:  UseShellExecute
* Found at end of powershell script on command line 
```.$.s...U.s.e.S.h.e.l.l.E.x.e.c.u.t.e.=.$.f.a.l.s.e.```
## What is the compression stream that has been used in the payload?
* **Answer**:  GzipStream 
* Found within the powershell encoded command that is seperated by periods 
```G.z.i.p.S.t.r.e.a.m.(.(.N.e.w.-.O.b.j.e.c.t. .S.y.s.t.e.m...I.O...M.e.m.o.r.y.S.t.r.e.a.m.```
## From the SAM and SYSTEM file that was exfiltrated, how many user passwords would've been identified?
* **Answer**: 6 (Administrator, Guest, IEUser, sshd, sshd_server,Sam)
* Dumped the SAM using [this](https://andreafortuna.org/2017/11/15/how-to-retrieve-users-passwords-from-a-windows-memory-dump-using-volatility/)
* hashes output to a txt file using hashdump
## What is the password of the SAM?
* **Answer**: StandardUser
* Cracked using online tool for NTLM hash cracking
## What is the password of the Admin?
* **Answer**: Passw0rd! 
* Used hashcat: ```hashcat -m 1000 -a 0 hash.txt ~/resources/wordlist/rockyou.txt```
## What is the port the attacker used to login to the system after cracking the passwords?
* **Answer**: Port 22
* View SSH activity in the packet capture that shows authentication attempts and full authentication between the source and destination IPs
## Are there any other scripts the attacker executed on the system? Find the name of the script
* **Answer**: ```jaws-enum.ps1```
* Viewed GET requests over port 80 with the ps1 in packet capture.
